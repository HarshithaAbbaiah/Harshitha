### 🚀 Featured Projects

#### 🔍 [Explainable AI-Based Credit Risk Assessment System](https://github.com/HarshithaAbbaiah)
Stacking ensemble (LightGBM + XGBoost + Logistic Regression) on the UCI credit card dataset — **84.4% accuracy, AUC 0.86**. Adds TreeSHAP/LIME explanations, a DiCE-ML counterfactual "What-If Simulator," a Fairlearn bias-mitigation module, and a rule-based XAI chatbot. Published as an IEEE paper. Deployed via FastAPI + React.
`Python` `XGBoost` `LightGBM` `SHAP` `LIME` `DiCE-ML` `Fairlearn` `FastAPI` `React`

#### 🤖 [Vault AI — RAG Pipeline](https://github.com/HarshithaAbbaiah)
Modular Retrieval-Augmented Generation pipeline achieving **88% context precision/recall** (Ragas evaluation). Hybrid retrieval with source-aware, citation-traceable answers; automated ingestion, chunking, and vector-indexing workflow.
`LangChain` `FAISS` `RAG` `Ragas`

#### 📦 Retail Customer Churn & Demand Forecasting (RFM Segmentation)
Global LightGBM forecasting model on **1.7M+ sales records**, cutting MAE by **36.3%** vs SARIMA/Prophet/rolling-average baselines. Engineered temporal + business features (lags, rolling stats, promos, holidays, SNAP events) and built an inventory optimization layer that cut simulated stockout days by **75% (4 → 1)** over a 28-day horizon.
`LightGBM` `Feature Engineering` `Time Series` `Inventory Optimization`
